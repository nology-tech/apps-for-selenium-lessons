# To Do App

# Running instructions

## Backend

Create a `.env` file by copying the provided example

```bash
cp .env.example .env
```

Update the values of the variables.

Then run

```bash
mvn spring-boot:run
```

Your database should get created and seeded on the initial run of the application.

## Frontend

Cd into the `todo-frontend` folder.

Run:

```bash
npm i
```

Then:

```bash
npm run dev
```
